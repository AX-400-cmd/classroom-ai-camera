智能课堂 AI 摄像头系统

基于 YOLOv8 的课堂行为分析 · 检测玩手机 / 打瞌睡 · 实时预览 · 告警留证

YOLOv8 Flutter 微信小程序 Python MIT License

行为检测

YOLOv8 + 目标跟踪，实时识别学生玩手机、打瞌睡（趴桌 / 低头）。

实时预览与录制

APP 端查看摄像头画面，可按需录制课堂视频留存。

告警留证

异常行为自动截图留证，并可选微信订阅消息推送到教师手机。

课堂统计

注意力、告警次数等数据落库，APP 端以图表可视化呈现。

快速开始

1) 安装依赖 pip install -r requirements.txt   2) 启动后端 python -m classroom_camera.api_server --source 0   3) 手机安装发行版 APK，填入电脑内网 IP 即可。
